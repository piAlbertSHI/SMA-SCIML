# 第 1 章：从一个物理项目走到可解释的 SciML 学习闭环

## 1.1 先用一句话理解我们在做什么

我们把一个“压力驱动的形状记忆合金薄板制冷数值模型”变成一套可复现的机器学习实验：
让模型预测性能、状态和温度场，检查它什么时候失败，再用不确定性指导选样与候选设计。
最终重点不是得到一张漂亮图，而是你能解释数据怎么来、代码怎么训练、误差怎么判断、下一步怎么自己改。

这不是把已有论文结果换几个 AI 术语。项目确实包含神经网络训练、坐标型 DeepONet、Fourier 对照、
物理损失、参数逆问题、集成校准、离线主动学习及 Pareto 候选回查；也包含神经网络不如简单模型的结果。
这些成功与失败都属于学习内容。

本报告默认你有数学背景，但不要求熟悉 PyTorch 或这个仓库。需要区分三个层面：

| 层面 | 你要回答的问题 | 本项目例子 |
|---|---|---|
| 物理问题 | 系统状态和输入输出是什么？ | 压力、相变、板温度、流体温度、热量和功 |
| 学习问题 | 什么在预测前已知，模型要预测什么？ | 用几何/控制预测 COP，或用初场预测后续温度 |
| 软件证据 | 你怎样证明程序做的就是所声称的任务？ | 数据切分、源摘要、梯度测试、重载重训、失败保留 |

后面每章都要把这三层接起来，而不是只展示网络结构。

## 1.2 物理背景：为什么机械加载会与制冷有关

研究对象是周边夹持的 NiTi 形状记忆合金（SMA）薄圆板。压力引起位移和大挠度，
应力驱动材料内部相变量变化；相变与温度耦合。用流体进行阶段性换热，形成数值制冷循环。
这里把负责热量输运的流体称作 HTF（heat-transfer fluid）。

一次循环可先按下列直观顺序理解，精确状态接口再见第 05、07C 章：

| 阶段 | 物理动作 | 模型必须记住的状态 |
|---|---|---|
| 1 加载 | 压力使薄板变形、相变量和温度改变 | u、w、xi、SMA 温度 |
| 2 放热换热 | 与放热方向的流体路径交换热量 | 固体方向性温度、活动 HTF、热端/侧节点 |
| 3 卸载 | 机械卸载伴随逆向相变与温变 | 重启后的机械状态、xi、SMA 温度 |
| 4 吸热换热 | 冷却后的薄板与相应路径交换热量 | 另一 HTF 路径、冷端/侧节点和循环末状态 |

u 是径向位移，w 是挠度，xi 是相变量（无量纲、范围 [0,1]）。
这不是“给定温度就能推知所有量”的系统：相变量具有历史，流体和侧节点也储存热量，
下一循环不能随意重置。空间温度分布还可能不对称，仅记一个均值会丢失信息。

已有求解链包含 51 节点径向机械/热模型以及 101 节点换热相关场，使用 MATLAB 与 Simulink/Simscape。
这些是数值观察，不是本任务新做的实物实验。历史计划提到的三维有限元对照属于数值一致性证据，
不能把它叫作实验验证。本报告不重复验证历史有限元模型，也不把历史加载数据库混入当前训练样本数。

## 1.3 输入、状态、输出：用三个数学对象整理项目

把预测前已知的几何、材料和控制记作 c，系统当前状态记作 z，性能指标记作 y。

第一类任务是直接性能回归：

\[
\hat y=f_\theta(c).
\]

例如 c 给出半径、厚度、压力、目标冲洗比、换热时长和材料类别，y 包含 Qcool、泵功、COP 等。
θ 是训练得到的参数。它不是必须可解释为某个物理材料系数；神经网络权重通常只是拟合参数。

第二类任务是状态转移：

\[
\hat z_{j+1}=F_\theta(\hat z_j,c,s_j).
\]

s_j 是阶段编号。推演时使用上一时刻自己的预测，误差会积累。若每步都给真实 z_j，
那只是单步预测，不是自主循环。这个区别是本项目最重要的检查点之一。

第三类任务是场映射：

\[
\hat T=\mathcal G_\theta(c,T_0,\text{side-state})(x,t).
\]

这里 T0 是允许已知的初始场，side-state 是主温度场之外但影响演化的节点/路径状态。
模型不仅接收几个数，也接收函数的离散采样，再在查询坐标输出温度；这是算子学习的入口。
连续坐标可查询不代表已经证明任意新网格、材料和时间跨度都准确。

## 1.4 为什么要先做简单模型

假如你的 DeepONet 测试误差为 0.6 K，这个数字本身不能告诉你是否值得用神经网络。
也许保持初始温度不变就有 0.5 K，也许低秩 POD 加线性回归更准确。
因此项目先做常数/持久性、Ridge、树模型，再比较 MLP、集成与算子。

baseline（基线）是同任务下的参照方法，不是随便挑一个弱模型来衬托新方法。
ablation（消融）是按预设条件去掉一个组件，观察变化。训练后把某个输入置零的干预与
去掉该组件后重新训练不是同一件事，后面会明确区分。

同样，“物理—神经混合”也要具体说明混合在哪：本报告当前状态模型主要是经验 Ridge 映射
加神经残差与状态约束，不等于每一步都调用完整物理求解器。
原计划的完整物理 closure 修正是更高阶方向，不能因为标题有 hybrid 就声称已实现。

## 1.6 三种证据边界，从第一页就要记住

1. **项目归档数据**：当前 63 个同版本单循环工况；另有独立版本的历史多循环，核验后分开使用。
2. **制造解教学问题**：例如已知扩散系数的热方程，目的是检验自动微分和逆问题算法，不冒充 SMA 物性辨识。
3. **离线闭环**：算法先选点，再揭示已有标签。它演示主动学习的信息权限，不是刚运行的新高保真仿真。

当前 63 例均通过归档中用于学习资格的记录检查，但这仍不是论文级普适泛化或独立能量闭合证明。
尤其本项目 COP 标签的分母是已有实现口径，实际为加载功加回收功量再加液压泵功，
不是已经验证的净电输入 COP。第 07A1 章专门给出源码与数值解释。

新材料外推失败、三循环神经模型不如线性基线、设计候选工程安全未知，都是保留下来的结论。
学习闭环要求你能解释它们，不要求每一个神经模型都胜出。

## 1.7 你需要掌握的最小机器学习词汇

- **样本/工况**：一组完整物理条件及对应结果；许多时间点不是许多独立工况。
- **特征 X / 标签 Y**：允许模型看到的输入与用于监督或评价的答案。
- **训练集**：用于拟合权重、归一化尺度及数据驱动基底。
- **校准集**：本项目主要用于调整不确定性区间，不用于网络梯度更新。
- **测试集**：评价约定任务；若反复用它选择方法，它就是开发参考，不再是未查看的独立确认。
- **epoch/update**：优化器更新单位；全批标量训练与抽样算子训练的“一步”不包含相同数据量。
- **loss**：优化时最小化的目标；它可能无量纲，不能直接当成有单位误差。
- **checkpoint**：保存的模型参数与必要的尺度/配置，不是只存网络权重就能复现全部预测。
- **OOD**：训练分布之外的输入，例如从未训练过的材料类别。
- **calibration**：把区间宽度与误差覆盖关系联系起来；不是把平均误差“校正为零”。

后续章节首次引入更复杂概念时会再配公式与实际数组，不要求你在此背完所有名词。

## 1.8 阅读与练习路线

第一遍先读 01–04，完成“打开一个工况、解释 X/Y、训练一个小模型”的基础练习。
第二遍读 05–07C，把每个模型的输入权限、状态 shape、时间接口画清楚。
第三遍读 07A2、08，实际求导并尝试制造一个不可辨识例子。
最后读 09–11，将预测、区间、选点、重训、设计回查接起来，再按第 12–15 章进行独立复现与验收。

不要把“看懂代码”当成“能实现”。每章的进阶练习都要求你在新文件/新输出目录改动一个假设，
说明预计变化，运行后比较，再保留失败证据。不能保证阅读本身带来熟练，但可以用这些任务检验掌握程度。

## 1.9 本章自测

问题：模型收到真实阶段 4 初始温度后预测准确，能否证明它能从循环开始自主预测阶段 4？
答案：不能。后者还需要预测前面阶段和接口，不能索取未来真实初态。

问题：为什么 63×50×101 个温度值不等于 318150 个独立工况？
答案：同一轨迹的时间/空间值受同一初态和物理条件耦合，跨集合会泄漏工况信息。

问题：制造热方程的 PINN 辨识正确，说明识别了 NiTi 换热系数吗？
答案：不说明。前者证明该教学方程的算法实现，后者需要正确物理方程、观测和可辨识性证据。

问题：完成学习闭环后应如何真实介绍项目？
答案：可以说完成了已有数值数据上的 SciML 方法实验与离线决策闭环，并公开报告误差和限制；
不能说完成实物验证、通用神经算子或完整设备安全设计。
