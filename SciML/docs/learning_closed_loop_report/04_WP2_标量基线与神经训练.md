# 第 4 章：WP2——从强基线到可审计的神经网络训练

## 4.1 为什么先预测几个数，而不是直接预测整张温度场

本章的任务是：给定一个工况的几何、压力、冲洗量和运行时间，预测一次循环
的制冷性能。这是多输出回归。先做标量任务的价值是把数据切分、归一化、
训练循环、基线比较、检查点和误差评价全部走通。到了场预测时，只需要增加
场结构和坐标处理，不必同时排查整个工程链。

“用了深度学习”不等于“深度学习是最佳工具”。最先应问：同样输入、同样训练
数据，线性回归和树模型做得怎样？我们不能拿一个没有认真配置的弱对照来
衬托神经网络。本章既给出了真实神经训练，也保留了强基线、失败消融和限制。

代码入口是 [learning_scalar_benchmarks.py](<../../models/v12/learning_scalar_benchmarks.py>)，
它是在原 [run_learning_existing.py](<../../models/v12/run_learning_existing.py>)
标量实验上的可追溯扩展，不覆盖原结果。审计脚本是
[audit_learning_scalar.py](<../../evaluation/audit_learning_scalar.py>)，
测试是 [test_learning_scalar_benchmarks.py](<../../tests/test_learning_scalar_benchmarks.py>)。

## 4.2 把物理问题翻译成 X 和 Y

每一行是一种物理工况，不是一个时间点，不是一条场内网格线。
63 个已完成有效工况按原条件哈希切分为 37 训练、13 校准、13 测试。
所有后续比较沿用这个切分，没有为了得到好看的分数重新打乱。

### 输入：7 个数

| 列 | 意义 | 单位/编码 |
|---|---|---|
| radius_m | 半径 R | m |
| thickness_m | 厚度 t | m |
| pressure_Pa | 设定压力 | Pa，不是 MPa |
| flush_volume_target_ratio | 目标无量纲冲洗体积比 | 无量纲 |
| exchange_duration_s | 配置的换热时长 | s |
| material_recA | 是否为 recA | 0 或 1 |
| material_recAs | 是否为 recAs | 0 或 1 |

材料编码使用 `design_matrix`，未知材料名会抛错，不会悄悄归入某个已知材料。
训练集含两种材料，但原测试集恰好只有 recA。因此本章测试分数不是材料外推
证据；结构化材料 OOD 见第 07B 章，分歧检测见第 9 章。当前半径与厚度按 R/t=200 成对变化，不能从
这批数据识别出任意独立改变 R 和 t 时的完整响应。

输入只能使用预测前已知的条件。不能放入实际制冷量、运行后的应力、挠度，
或由目标计算的指标。把这些放进去即使测试分数很好，也无法用于真正的事前预测。

### 输出：5 个数

| 列 | 物理含义 | 单位 |
|---|---|---|
| Qcool_J | 该循环按既有定义统计的制冷量 | J |
| Wpump_J | 归档液压泵功估计，不含电机效率 | J |
| COP | Qcool / Wtotal_for_COP | 无量纲 |
| SCP_W_per_kg | Qcool / (SMA 质量 × 循环时长) | W/kg |
| deltaT_hot_cold_max_K | 记录定义下的最大冷热温差 | K |

COP 和 SCP 的导出公式可在
Export_SCIML_V11_Case.m（原工作站归档，未随精简分发打包）找到。
这些数继承求解器的能量与性能边界，不是全设备寿命周期指标，也不是实验测量。
新增能量读出审计发现，全部 63 例的 `Wtotal_for_COP_J` 实际等于加载功加回收功量再加泵功，
并非“加载功减回收功”的理想净输入定义。这里预测的 COP 严格指这个归档标签，不作设备 COP 解读。
具体源码、符号和数值核对见[能量读出与标签口径](<07A1_温度场到能量的读出契约.md>)。
WP6 另有六输出模型多预测 Wtotal；本章统一用五输出，防止把输出任务的变化
误认为集成方法本身的收益。

张量约定：X 为 63×7，Y 为 63×5；训练时取 X_train 为 37×7，Y_train 为
37×5。代码使用二维数组，不把第 2 维的五个目标展平成 185 个独立工况。

## 4.3 归一化为什么是数学问题，而不是美化数据

半径约 0.04 m，压力约 10^6 Pa。输出中泵功约 10^-3 J，而 SCP 是数百 W/kg。
如果直接把原数值送进网络并求一个平均平方误差，参数尺度和损失尺度都不协调。

训练集标准化：

\[
\widetilde x_{ik}=\frac{x_{ik}-\mu_{x,k}}{s_{x,k}},\qquad
\widetilde y_{ij}=\frac{y_{ij}-\mu_{y,j}}{s_{y,j}}.
\]

均值与标准差只由 37 个训练工况计算。校准和测试只调用 `transform`，不能
重新 `fit`，也不能对完整 63 行先 fit 再切分。若未来查询单个工况，也必须使用
保存的相同参数。预测后用反变换 y_hat=s_y*y_tilde_hat+μ_y 恢复物理单位。

`StandardScaler` 的方差采用分母 n，不是 pandas `std()` 默认的 n−1。
本次保存的五目标标准差为：

```text
Qcool: 4.08654443858658 J
Wpump: 0.0007372757033463108 J
COP:   0.4298753220462959
SCP:   192.45963754954937 W/kg
deltaT:0.379391845926395 K
```

这使训练目标等价于原单位误差按 1/s_y,j² 加权，而不是声称五个指标在工程上
同等重要。若项目有真正的容许误差，可以另行设计固定权重，但不能根据测试
结果反向选择权重，然后声称事先如此。

一个手算例子：泵功误差 0.0001 J 对应标准化误差约 0.136；SCP 误差
20 W/kg 对应约 0.104。若直接平方原数值，前者约 10^-8，后者 400，
小量纲输出几乎不参与总损失的数值大小。

## 4.4 七种报告行到底对应什么模型

| 报告名称 | 做法 | 在比较中的角色 |
|---|---|---|
| train_mean | 所有预测固定为训练目标均值 | 最低限度可用性基线 |
| ridge | 标准化输入/目标，线性岭回归，alpha=1 | 平滑低复杂度基线 |
| random_forest | 200 棵树、bootstrap、每叶至少 2 样本、全部特征可用 | 多输出随机森林基线 |
| hist_gradient_boosting | 每目标独立 HistGB，200 轮、学习率 .05、最多 7 叶、每叶至少 3 例、L2=.1 | 非线性提升树基线 |
| mlp | 五成员模型的第 1 个网络，7→32→32→5 | 单网络深度学习模型 |
| ensemble5 | 同样五输出的 5 个独立初始化网络取预测均值 | 直接检验集成的作用 |
| mlp_raw_targets | 同一单网络结构与种子，但去掉输出标准化 | 目标尺度消融，非推荐模型 |

随机森林在这里是一棵树共享五输出的多输出模型，切分时看标准化后的多目标
误差；HistGB 用 `MultiOutputRegressor` 为每个目标训练一个模型。两者的共享
结构不同，应记录清楚，不把它们说成完全相同的模型只换了优化器。

树模型使用单线程；HistGB 关闭 early stopping，所有配置固定在首次运行前，
没有搜索超参数。它们是合理的强基线配置，不是穷尽调参后的算法上限。
“公平”指信息和评价口径一致，并不表示每种模型的计算量完全相等。

### 小样本默认参数陷阱

HistGB 默认 `min_samples_leaf=20`，37 个训练样本不够形成两个至少 20 例的叶子。
审计实际拟合了默认模型，确认它只能输出常数。正式对照提前设为 3，避免这种
退化。官方文档也提示小数据集应降低此参数；不要照抄大数据教程的默认值。
[HistGB 官方参数说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)

本次 HistGB 三颗种子预测相同是可以解释的：固定数据、固定配置，没有启用
随机子采样或随机早停拆分。Ridge 本来也不依赖种子。因此它们的种子标准差
接近零，不意味着泛化误差没有不确定性，只表示本实验没有改变这些模型的拟合结果。

## 4.5 神经网络的每一步计算

模型为：

\[
h_1=\operatorname{SiLU}(XW_1^T+b_1),\quad
h_2=\operatorname{SiLU}(h_1W_2^T+b_2),\quad
\widehat{\widetilde Y}=h_2W_3^T+b_3.
\]

SiLU(z)=z·sigmoid(z)。它给模型非线性表达能力；如果去掉所有激活函数，
多层线性变换仍然可以合并成一个线性变换。

| 运算 | PyTorch 参数形状 | 训练批输出形状 | 参数数 |
|---|---|---|---:|
| Linear(7,32) | W:32×7，b:32 | 37×32 | 256 |
| SiLU | 无参数 | 37×32 | 0 |
| Linear(32,32) | W:32×32，b:32 | 37×32 | 1056 |
| SiLU | 无参数 | 37×32 | 0 |
| Linear(32,5) | W:5×32，b:5 | 37×5 | 165 |
| 合计 | — | — | 1477 |

只有 37 个训练工况，却有 1477 个参数，因此不能靠参数数量直觉保证泛化。
控制网络规模、保留基线、隔离工况和报告测试误差，比把网络改得更深更重要。

优化目标是五目标标准化 MSE：

\[
\mathcal L=\frac{1}{37\times5}\sum_{i=1}^{37}\sum_{j=1}^{5}
(\widehat{\widetilde y}_{ij}-\widetilde y_{ij})^2.
\]

这一个标量在 `loss.backward()` 后产生对所有参数的梯度。对输出分量，
梯度为 2*(预测−目标)/(37×5)，其余由链式法则自动传播。
不要在计算 loss 前对训练预测调用 `.detach().numpy()`，否则切断计算图。

实际训练参数：float64、CPU、全批次、300 次更新、AdamW 学习率 .002、
weight_decay=10^-4、全局梯度范数上限 10。由于每轮用全部训练集，
本章一个 epoch 对应一次 optimizer step；以后改成 mini-batch 后两者不再相等。

完整训练骨架：

```python
optimizer = torch.optim.AdamW(network.parameters(), lr=.002, weight_decay=1e-4)
for update in range(300):
    optimizer.zero_grad(set_to_none=True)     # 清掉上一轮梯度
    prediction = network(tx)                # tx: [37,7]
    loss = torch.mean((prediction-ty)**2)    # ty: [37,5]
    if not torch.isfinite(loss):
        raise RuntimeError("先诊断非有限损失，不盲目重跑")
    loss.backward()                         # 自动微分
    torch.nn.utils.clip_grad_norm_(network.parameters(), 10., error_if_nonfinite=True)
    optimizer.step()                        # 只在这里更新参数
```

AdamW 的 weight decay 是优化器中的参数衰减，不是本脚本额外写进 loss 的
物理惩罚。WP2 这里没有 PDE、能量守恒或阶段连续损失，不应把它叫成 PINN。

`eval()` 切换推理模式；`torch.no_grad()` 禁用梯度记录，节省推理开销。
本网络没有 dropout/BatchNorm，所以 eval 不改变这些层的数学结果，但仍应
保持训练/推理接口习惯。`fork_rng` 退出后恢复随机状态，避免一个教学实验
改变同进程其他任务的随机序列；Torch 线程数也在 finally 中恢复。

## 4.6 曲线记录与标签泄漏的边界

`fit_tracked` 在完成 0、50、100、150、200、250、300 次更新后记录：

- 训练目标函数值；
- 用训练目标尺度统一衡量的训练/校准 MSE；
- 原单位下的五目标训练/校准 RMSE。

校准标签只用于 `no_grad` 诊断，不反向传播，也不触发 early stopping 或模型
选择。测试标签根本不传入 `fit_tracked`。单元测试将校准标签整体增加 1000，
发现曲线数值改变，而最终网络预测完全不变，实证检查了这条权限边界。

第一颗种子的曲线如下：

| 已完成更新 | 训练标准化 MSE | 校准标准化 MSE |
|---:|---:|---:|
| 0 | 0.977666 | 0.676493 |
| 50 | 0.154672 | 0.181266 |
| 100 | 0.019459 | 0.027173 |
| 150 | 0.004494 | 0.018867 |
| 200 | 0.002450 | 0.014070 |
| 250 | 0.001677 | 0.011238 |
| 300 | 0.001231 | 0.009293 |

从第 50 次更新的记录起，校准误差高于训练误差，说明拟合数据与未训练数据之间有差距；
第 0 次更新时校准误差反而较低，不应把后期关系误说成全部记录点都成立。但曲线记录点
中的校准误差仍在下降，因此不能说“本次观察到校准误差回升式过拟合”。
也不能因此擅自把训练延长直到测试分数最好：300 更新是本次固定预算。

本章是优化步数曲线；第 10 章的 12→17→22 是标签预算曲线。
增加训练更新和增加独立工况是两种不同资源，不能混用一个横轴。

## 4.7 为什么去掉目标归一化会失败

消融保持输入标准化、网络结构、初始化种子、学习率、衰减、梯度裁剪与更新数
不变，只让网络直接拟合原单位目标。为了使用通用集成检查点格式，程序保存了
两个 raw-target 成员；本章只评价第一个成员，第二个未取平均，不能把它算成
更强的消融结果。

第一颗种子中，原单位 MSE 从 73437.4 降到 18799.1，看起来“优化在进步”。
但同一模型的训练标准化 MSE 从约 4856 降到 464 后又升到 3579。
两个指标不矛盾：原单位目标在奖励 SCP 等大数值量的误差下降，小尺度输出
即便显著恶化，也可能被总损失掩盖。梯度裁剪不会替你完成单位平衡。

这个消融改变了目标中心化、缩放和优化条件，也改变了物理单位下的有效损失
权重。因此它证明的是“在固定预算和配置下，整个目标标准化步骤很重要”，
不是精确分离中心化与缩放各自的因果贡献。进一步区分需要新增受控消融。

## 4.8 指标如何算，为什么不能只看 R²

对某一个目标、测试集中 n=13 个样本：

\[
\mathrm{RMSE}=\sqrt{\frac1n\sum_i(\hat y_i-y_i)^2},\quad
\mathrm{MAE}=\frac1n\sum_i|\hat y_i-y_i|.
\]

RMSE 对大误差更敏感；MAE 更直观；max_abs 说明最差点的绝对偏差。
这些值保留目标原单位，不把 K、J 和 W/kg 混合成一个物理含义不明的 RMSE。

\[
R^2=1-\frac{\sum_i(\hat y_i-y_i)^2}{\sum_i(y_i-\bar y_{test})^2},\quad
\mathrm{skill}=1-\frac{\mathrm{RMSE}_{model}}{\mathrm{RMSE}_{train\ mean}}.
\]

这里 R² 分母用测试标签的均值，这是评价定义，不是拿测试均值做预测。
train_mean 基线则只能用训练均值。两者不能互换。skill<0 表示比训练均值
还差；R²<0 表示比测试均值这个参照还差，负值应保留而不是截成零。

标准化 RMSE=原单位 RMSE/训练目标标准差，只用于跨目标画图。
它不是“相对误差百分比”；当目标接近零时，逐点相对误差可能极不稳定。

## 4.10 检查点、重训、审计为什么各做一次

完整复现不止是“脚本退出码为零”。我们检验三个层次：

1. 保存/加载一致：`.pt` 使用 `weights_only=True` 读取张量和基本元数据，
   保存网络参数、输入/输出尺度、训练 ID、种子、配置和曲线；冷加载预测逐值一致。
2. 重训一致：审计重新训练 3×(5+2)=21 个网络，预测与曲线逐值一致；
   独立重训 Ridge、RF、HistGB 并重算全部指标。
3. 历史锚点一致：第一颗种子的五输出单网络逐值复现原 WP2 的 neural 预测，
   说明本次加入曲线记录没有改写原训练算法。

经典模型使用本地生成的 pickle 保存。审计先验证产物哈希，且只加载本任务
自己生成的文件；不要把这个流程当作任意下载 pickle 都安全。以后分享模型，
应明确环境版本和文件信任来源。

产物目录：`SciML/results/learning-closed-loop-20260910/wp2-strong-r1`。

## 4.11 分级练习：从读懂到能独立实现

### 练习 A：形状、参数数和一步梯度

手算 7→32→32→5 的参数数；说明为什么输出层没有 SiLU；写出标准化 MSE
对预测数组的梯度。再把一个 batch 改成 4 个工况，列出每一层输出形状。

答案：1477；输出层保持可取正负的标准化实数，不应把标准化后的负值误判为
负物理功；梯度 2*(预测−目标)/(batch_size×5)；输出依次 4×32、4×32、4×5。

### 练习 B：手算一个指标

真值 [1,3]，预测 [2,2]，训练均值预测也是 [2,2]。求 RMSE、MAE、R²、skill。

答案：RMSE=1，MAE=1，R²=0，skill=0。再把预测改为 [101,103]，R² 会为负，
不得截断。若测试目标常数，R² 分母为零，本实现返回 null，不伪造有限分数。

### 练习 C：复现信息隔离测试

不看测试标签，把校准标签打乱或加一个大常数，两次用相同种子拟合。
验证权重或预测完全一致，而校准曲线不同。然后故意写一个“校准变差就提前停”
版本，观察为什么此时校准标签开始影响参数。

验收：你能区分诊断数据、调参验证数据和最终测试数据；若使用校准集调参，
后续置信区间应重新考虑校准数据独立性，而不是继续无条件引用旧覆盖说法。

### 练习 D：半指导添加二次 Ridge

在经典基线工厂中增加训练集拟合的二次特征变换，再使用 Ridge；把变换器一起
放进检查点，训练和预测使用同一个变换。保留截距约定，不重复手加常数列。
使用新的输出目录记录协议，不改写本章 r1。先在合成二次函数上验证，再做
已有切分的探索比较。

验收：新增特征未使用输出；转换器只拟合训练输入；审计能冷加载复现；
若二次 Ridge 更好就如实报告，不能因目标是学习深度学习而隐去结果。

### 练习 E：独立实现一个陌生回归任务

给你一份新物理数据，先写出输入可用时点、目标单位、工况分组键和切分原则；
实现训练均值与线性基线，再实现 MLP、训练曲线和一项可解释消融。提前固定
预算和指标，保存检查点、测试所有错误输入，并给出至少一个不支持泛化的场景。

完成标准不是“命令能运行”：你应能从一个异常曲线定位到单位、切分、梯度、
容量或优化器层面；能解释树模型为什么需要适配样本规模；能说明哪项结论
来自真实结果，哪项只是可能机制。达到这个标准后，再进入 WP3/WP4 才有基础。
