# SMA–SciML 项目闭环学习报告（学习交付版）

本报告属于 2026-09-10 的完整学习闭环目标，不是前一份简短学习指南的改名。
目标是让读者能够解释、复现、排错并自行扩展算法，而不只是知道运行命令。
完整走查与逐项结论见双重终审记录（原工作站归档，未随精简分发打包）。
最终机器证据的位置与生效条件见第 15 章：必须同时匹配当前章节、源码与实际测试结果。

## 读者起点与阅读方式

默认你有数学基础，但未必熟悉 PyTorch、机器学习实验设计或本仓库。
正文先用项目任务解释概念，再给公式、张量形状、函数入口和实际结果。
每个算法章都应包含：问题 -> 最小数学模型 -> 数据可见性 -> 实现 ->
训练/评价 -> 失败分析 -> 复现命令 -> 练习 -> 参考答案和掌握标准。
熟悉的部分可以跳到实现细节，陌生的概念应先完成章末小练习。

## 三种证据不可混在一起

- **项目数值数据**：63 个同版本有效工况，以及另行核验的历史轨迹。
- **制造解教学实验**：为了知道真正答案而专门构造的数学问题，不冒充 SMA 物性辨识。
- **离线闭环**：算法选择一个未向它公开标签的已有工况，再揭示归档数值结果。
  这能演示选样和更新流程，但不是新启动高保真求解器或完成设备设计验证。

任何以前已经看过的测试分数，后续使用时都属于开发/探索证据，不能重新命名为独立确认。

## 报告的验收方式

可读性审查：每章的术语有首次解释，公式有变量/单位/形状，代码能定位，
一个不熟悉仓库的读者能按命令重现并解释输出。
技术完整性审查：每项实际配置、来源、损失、基线、负结果和限制都能追溯到文件；
练习具有可检查答案；图表与保存数组一致；不以短单元测试代替科学性能验证。

读懂报告是起点，能否独立实施需要通过练习与验收题检验。
不能保证仅阅读文字就自动熟练掌握；第 14 章提供明确、可操作的自测标准：
8 个可执行参考题、3 个独立实现任务、5 个高阶任务规格及 0–3 级评分量表。
