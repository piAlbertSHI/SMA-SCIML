# 第6章 WP4：从场压缩到坐标神经算子，再到空间记忆传递

本章解决两个不同的问题。第一，已知一个换热阶段的入口温度场，能否快速
预测这个阶段内部的温度演化？第二，从循环开始时的请求参数出发，没有真实
阶段入口场可用时，怎样把上一章的状态模型接到场模型上？

这两个问题的输入权限不同。前者是“阶段条件预测”，后者是“请求到场的自主
级联”。本章分别训练、测试、报告，不把真实阶段4初场偷偷当成循环初始输入。
全部实验复用现有63例，没有新增 MATLAB 求解。主比较含三个种子、四种网络，
外加相同稀疏监督网格的 POD/Ridge。空间记忆修复使用事先固定的首个种子，
不选择最佳模型，也不再训练。

读完应能：写出 branch/trunk 的张量乘法，解释 Fourier 层的作用，实施硬初始
条件和匹配监督的对照，定位接口丢失状态的错误，独立复现保存的预测。

## 6.1 为什么标量网络和阶段末状态仍不够

WP2 输出一个工况的性能数字。WP3 输出若干阶段边界上的状态。本章输出
“每个时刻、每个位置”的温度，因此可以观察温差前沿、早期瞬态和空间误差。
只把所有网格值展平成一万个输出也能回归，但不自动得到坐标查询能力。

这里的算子任务写为

\[
\mathcal G:(T_{s,0}(x),T_{f,0}(x),\mu,z_{\rm side},k)
\mapsto (T_s(x,t),T_f(x,t)),
\]

其中 s/f 分别指 SMA 固体和 HTF 流体，温度单位 K；\(\mu\) 是几何、材料和
请求控制参数，\(z_{\rm side}\) 是边侧热节点状态；阶段标记 \(k\) 取2或4。
算子强调“输入中有一个场，输出也是场”。计算机仍以离散传感节点表示输入。
当前模型固定使用101点入口场；输出坐标可变，不意味着输入任意网格也已支持。

本章没有训练相变量 \(\xi\)、挠度 \(w\) 的坐标输出，也没有把实际压力/阀门
时间函数作为任意函数输入。当前控制分支是有限维请求参数；这比原计划的
完整控制函数算子更受限。不要从“multi-branch”名称推断不存在的功能。

## 6.2 从63个工况得到什么张量

读取入口为
learning_coordinate_operator.py（原工作站归档，未随精简分发打包）
中的 `corpus`，底层使用 `build_operator_corpus`。工况按固定次序排列，每例
依次提供 stage2、stage4 两个样本。因此126个阶段样本不是126个独立工况。
同一工况的两阶段始终留在同一集合：37/13/13个工况对应74/26/26个阶段样本。
测试集以前已被检查，当前比较是开发性实验，不是全新的独立确认。

| 数组 | 全部样本形状 | 语义 |
|---|---|---|
| `branch` | (126,221) | 入口场编码、阶段/材料/控制、side-state |
| `initial` | (126,2,101) | 两个真实入口场，K |
| `truth` | (126,2,50,101) | 原生导出的阶段温度历史，K |
| 训练监督子网格 | (74,2,26,51) | 仅这些时空点参与损失和输出缩放 |
| 一次小批次标签 | (16,2,6,51) | 16个阶段样本、随机6个监督时刻 |

`initial` 是从 `truth[:,:,0]` 拷贝出的阶段入口输入。因此完整首帧即使部分
节点不进入损失，也不是“未见标签”。评价留出坐标时必须排除整行首帧。
训练代码可以把完整数组载入内存，但损失和归一化只读规定的监督子集；本章
还通过污染未监督标签后重训来检查这一点，而不是仅相信变量名。

221维 branch 的切片如下，所有区间是 Python 左闭右开区间：

| 切片 | 个数 | 内容 |
|---|---:|---|
| `0:101` | 101 | SMA 首帧减去自身空间算术均值 |
| `101:202` | 101 | HTF 首帧减去自身空间算术均值 |
| `202:204` | 2 | 上述两个绝对均温，K |
| `204:206` | 2 | 阶段2/4 one-hot |
| `206:208` | 2 | recA/recAs one-hot |
| `208:213` | 5 | R(m)、厚度(m)、压力(Pa)、flush比、换热时长(s) |
| `213:221` | 8 | sink/chip/buffer/path-pipe 等 side-state 温度 |

拆成“温度形状+绝对均温”使二者可使用不同的尺度。算术均温只是特征，不能
当成圆板能量积分。非活动路径使用与训练一致的293 K编码，并靠阶段语义区分，
并不表示不存在的实体真的具有293 K物理温度。本模型不输入实际未来流量轨迹，
也排除了训练中恒定的循环编号。排除编号不能证明剩余状态已足够构成 Markov 状态。

输入的均值、标准差只从74个训练阶段样本拟合。实际除数取
\(\max(\mathrm{std}_{train},\mathrm{floor})\)。floor 分别为：场形状0.5 K、
绝对均温及 side-state 5 K、阶段/材料0.5，以及控制量
\((0.003\,m,1.5\times10^{-5}\,m,10^5\,Pa,0.1,0.4\,s)\)。
这是防止小样本近常量通道被放大的数值设计，不是测量误差，也不是人为增广数据。

## 6.3 两种空间坐标不能混为同一个物理轴

时间使用 \(\tau=t/t_{exchange}\in[0,1]\)。SMA 的101点位于直径条带
\(x_{strip}\in[-R,R]\)，其归一化坐标为 \(q_s=(x_{strip}+R)/(2R)\)。
HTF 使用路径内部节点序号，\(q_f=(j-1)/100\)，而不是相同的米制板直径。
两者都用数值区间[0,1]查询，但物理含义不同，输出通道也分开。

原生50个时刻均匀覆盖阶段；训练索引为 `0,2,4,...,48,49`，共26点。
最后48→49的时间间隔是前面间隔的一半，不能用26点均匀时间网格代替它。
训练空间索引为 `0,2,...,100`，共51点。

在原生50×101网格评价，检验的是同一求解器离散结果的留出坐标预测。
程序另查询4个时刻 `[0,.137,.731,1]` 和201个位置，保存形状 `(1,2,4,201)`。
这只是接口测试，没有201点新求解器真值，不能写成“跨求解器网格精度已验证”。

`interpolate` 在入口101点上做分段线性插值，拒绝越界和非递增源坐标。
初始网格以 NumPy float64 创建，再注册为 PyTorch buffer。先用默认 float32
生成网格再转 double，不会恢复已舍入的坐标，这是保证原生节点首帧逐位一致
时容易忽略的细节。

## 6.4 多分支 DeepONet：怎样在任意查询点给出温度

把 branch 理解为“这个工况是什么”，trunk 理解为“我要查询哪里、什么时候”。
本实现的三分支为入口场204维、阶段/材料/控制9维和 side-state 8维，
不是原计划逐字指定的几何分支/控制函数分支/初场分支划分。

每个分支均为 `input→32→32→32`，前两隐藏层使用 Tanh。
拼接为96维后，经 Tanh 和线性层输出48个系数，reshape为 `(B,2,24)`。
trunk 输入 `(2q-1,2τ-1)`，经过 `2→32→32→48`，输出 reshape 为 `(Q,2,24)`。
其中 B 是批量阶段样本数，Q 是查询时间数乘位置数，24是每个场的潜在基数。

第 f 个场的无量纲网络输出为

\[
N_f(b,q,\tau)=\frac{1}{\sqrt{24}}\sum_{\ell=1}^{24}
a_{f\ell}(b)\,\phi_{f\ell}(q,\tau)+\beta_f.
\]

代码的核心乘法是 `torch.einsum("bfl,qfl->bfq", coefficients, trunk)`。
重复指标 l 求和，保留样本 b、场 f、查询 q。最终还原 `(B,2,Nt,Nx)`。
不是把查询坐标复制进每个工况参数后训练一个巨大输出层；坐标基函数本身
由 trunk 学习，工况通过 branch 改变组合系数。当前总可训练参数20,898个。

需要区分此模型与旧 POD 原型：POD 基底先由训练场 SVD 固定，只学习系数；
这里坐标基底也在监督训练中学习。后者提供连续坐标函数接口，不保证数据量
很小时更准，更不保证满足 PDE。

## 6.5 硬初始条件：不靠惩罚权重去“尽量接近”首帧

模型不是直接输出绝对温度，而是

\[
\widehat T_f(q,\tau)=IT_{f,0}（原工作站归档，未随精简分发打包）
+s_f\,(1-e^{-4\tau})\,N_f(b,q,\tau).
\]

\(I\) 是初场插值；\(s_f\) 是训练粗网格上 `truth-initial` 的 RMS，单位K，
最小取0.1 K。门函数 \(g(\tau)=1-e^{-4\tau}\) 在0处严格等于0。
因此不论网络权重是什么，\(\widehat T_f(q,0)=IT_{f,0}（原工作站归档，未随精简分发打包）\)。
代码使用 `-torch.expm1(-4*times)` 计算门函数，改善小时间数值计算。

这是硬 IC（initial condition，初始条件）构造，不是 PDE 约束，不是空间边界
条件，也不保证跨阶段输入来自正确物理状态。真实入口场条件预测首帧误差为0；
若入口由 WP3 预测，硬 IC 只保证忠实承接“预测入口”，相对真实入口仍可能有误差。

消融 `deeponet_no_ic` 保持相同初始场残差形式，但把门函数替换为1。
它能自由调整首帧，检验首帧一致性对当前任务的作用。不要称它为“完全无初场
输入”：初场仍在 branch 和加法基底中。

## 6.6 Fourier 对照到底实现了什么

`ConditionalFourier` 是**按时间条件化的一维空间 FNO**，不是二维时空 FNO，
更不是 UNO。每个查询时刻在空间轴上做卷积；时间作为输入条件，不做时间FFT。

计算路径如下：

1. 入口两温度场在查询网格插值，按 `(T-293)/5` 数值缩放；拼接 q、τ，得到4通道。
2. 用1×1卷积把4通道提升到宽度12；标准化的221维全局 branch 线性映射到12维，
   广播到所有位置和时刻后相加。
3. 空间右侧补 `max(1,Nx//4)` 个零，做两层 spectral+local 运算，每层之后 GELU。
4. 去掉补零区，经过 `12→16→2` 的1×1卷积投影，最后施加与 DeepONet 相同的硬 IC。

一层的概念公式为

\[
v_{l+1}=\mathrm{GELU}\{\mathcal F^{-1}[R_l(k)\mathcal F(v_l)(k)]
+W_l v_l+b_l\}.
\]

`rfft` 利用实数输入的频谱对称性，最多保留8个低频模式，在模式内混合12个通道。
实际数量为 `min(8, rfft输出频率数)`；小查询网格可用频率不足时不会凭空补出更多模式。
高频的谱分支置零，但还有逐点 local 分支，不意味着整个输出严格低通。
复权重存成 `(12,12,8,2)` 的实数组，最后一维是实部/虚部，再通过
`view_as_complex` 运算；单位测试确认这些权重确实收到非零梯度。
FFT 使用 `norm="ortho"`，逆变换显式传入空间长度。

补零是减轻周期绕回影响的数值技巧，不是推导出的物理边界条件。该模型拒绝
非均匀、非完整[0,1]的查询网格和不足8个位置的网格；DeepONet 无此均匀网格限制。
Fourier模型共7,886个实参数。小于 DeepONet 不等于更快，频谱运算和张量展开也有成本。

## 6.7 训练循环：400次更新，不是400次遍历数据集

两个主模型和两个消融使用同样的400次 AdamW 更新，学习率0.002、weight decay
为 \(10^{-5}\)，float64、CPU单线程、梯度范数裁剪上限10。不同网络参数量和
计算量不同，所以这是相同更新预算，不是精确相同 FLOPs 或最优调参预算。

每次从74个训练阶段样本无放回抽16个，再从26个监督时刻无放回抽6个并排序，
空间固定使用51个监督位置。同一 seed 的所有变体使用相同抽样序列
`np.random.default_rng(seed+77)`。模型初始化另由 PyTorch seed 控制。
三个种子为20260910、20260911、20260912；没有根据测试成绩早停或选最佳轮次。

损失为两个场各自按残差尺度归一化后的平均平方误差：

\[
L=\frac{1}{B\cdot2\cdot N_t\cdot N_x}
\sum_{b,f,i,j}\left(\frac{\widehat T_{bfij}-T_{bfij}}{s_f}\right)^2.
\]

训练顺序是 `zero_grad → forward → finite检查 → loss.backward → clip_grad_norm
→ optimizer.step`。不应忘记清梯度，否则默认行为是累积梯度。非有限损失或
梯度会停止，而不是把 NaN 换成0继续训练。

每50步及最后一步记录当前抽样损失。seed20260910 DeepONet 的记录从0.942874
降到0.016386，但这些点来自不同小批次，不是完整训练集固定损失曲线。
它只能辅助排错，不可当成单调收敛证明。原始数值保存在 `summary.json/history`。

## 6.8 为什么要重新做“相同粗网格”的 POD/Ridge

若 POD 使用全部50×101标签，而新网络只用26×51，直接排名就同时改变了监督量。
本章在 `audit_learning_operators.py/matched_pod` 中重新构建公平得多的基线：

1. 取相同粗网格，减去101点初场在监督位置上的值。
2. 只用训练样本估计阶段2、4各自的平均残差，并扣除阶段平均。
3. 对每个场的训练残差矩阵做 SVD，取前4个右奇异向量为 POD 基底。
4. Ridge(alpha=1) 从相同标准化 branch 回归4个系数。
5. 重建粗网格，加入阶段平均和初场；用真实粗时间坐标的线性插值回到原生网格。
   最后把首帧显式设为初场，保证硬 IC。

若残差展平为 \(D\in\mathbb R^{74\times1326}\)，基底
\(V_4\in\mathbb R^{4\times1326}\)，系数为 \(DV_4^T\)。这里每个场分别做SVD。
这是强低秩基线，不是神经网络。其基底、Ridge权重、截距、阶段均值和缩放量
均保存到 `coarse_pod_parameters.npz`，不能只留下最后一张图。

## 6.10 接到 WP3 后，为什么突然变差

上一章边界模型输出414维状态，其中 SMA 温度只有51个径向点。最初级联
把径向温度按 `[radial[:0:-1], radial]` 镜像成101点，然后作为阶段2/4的初场。
这默认了左右对称。流体沿一个方向流动后，板的真实温度不必对称。

检查全部63例得到：阶段2初场确实等于径向镜像；阶段4初场全部含非镜像分量。
简单镜像相对真实阶段4初场的最大误差3.355853 K，总体RMSE约1.375916 K。
所以这里不是“网络层数不够”，而是给网络的入口状态已经丢失了信息。

定义反射算子 J：把101点向量反转。任意向量分解为

\[
T=T^++T^-,\qquad T^+=(T+JT)/2,\quad T^-=(T-JT)/2.
\]

\(T^+\) 对称，\(T^-\) 反对称。51点径向状态最多表达镜像部分，无法单独
确定另外50个独立的反对称自由度。例如 \(293+x^2+2x\) 和
\(293+x^2-2x\) 具有相同对称分量，却有相反的左右温差。

本数据中逐例验证了关系：

\[
T_{strip,4}^{in}=\mathrm{mirror}(T_{r,4}^{in})
+\tfrac12(T_{strip,2}^{out}-J T_{strip,2}^{out}),
\]

63例最大误差仅 \(5.68434\times10^{-14}\) K。对应物理实现可定位到
AER_OperatorSplit_Bed.m（原工作站归档，未随精简分发打包）
的 `apply_mechanical_checkpoint_delta`、`nonmirror_delta` 和 persistent

## 6.11 修复不是读取真实未来，而是携带自己预测的空间记忆

`learning_operator_cascade.py/predict_cascade` 的输入签名只有边界模型、场模型、
请求字典和case IDs，没有 `truth` 或真实阶段4初场参数。推理顺序如下：

```text
请求参数 → WP3自主四阶段边界预测 → B2、B4径向/流体/side-state
                               B2 → DeepONet阶段2全场预测
                                      ↓ 预测末场的反对称分量 m
                         B4径向镜像 + m → DeepONet阶段4全场预测
```

具体步骤：先用预测B2拼成阶段2入口场；预测阶段2；计算
`memory=.5*(predicted_stage2_sma_end-reverse(...))`；向预测B4的镜像初场加入
memory；重新计算SMA中心化特征和均温，再预测阶段4。
如果仅修改 `initial` 而不更新 `branch[:101]` 和 `branch[202]`，模型会收到
两个不一致的入口场表示。本章函数同时更新二者，并拒绝非有限、长度不对或
不满足反对称关系的 memory。

固定首种子20260910的结果如下。此表不是三种子均值；条件入口模型只是参照，
它有真实入口场，不能与请求级联当成同输入公平排名。

| 输入方式 | S2 SMA RMSE | S2 HTF RMSE | S4 SMA RMSE | S4 HTF RMSE |
|---|---:|---:|---:|---:|
| 真实阶段入口 DeepONet | 0.576829 | 0.790997 | 0.571174 | 0.515266 |
| WP3请求级联，仅径向镜像 | 0.580378 | 0.791078 | 1.696596 | 1.359016 |
| WP3请求级联，加预测空间记忆 | 0.580378 | 0.791078 | 0.592715 | 0.610452 |

修复恢复了接口所需的信息类型，不能消除上游模型本身的预测误差。

## 6.15 分级练习、答案与掌握标准

### A. 手算张量与硬 IC

问题：批量3个阶段、7个时刻、11个位置，DeepONet潜维24。trunk最后的形状、
branch系数形状、einsum输出形状各是什么？τ=0时网络残差会改变初始场吗？

答案：`(77,2,24)`、`(3,2,24)`、`(3,2,77)`，再reshape `(3,2,7,11)`；
硬IC门函数为0，不改变初场。Fourier不能直接用任意11个位置，必须是完整均匀网格。

### B. 手算空间记忆

令 \(T(x)=293+x^2+2x\)，x为[-1,1]上101点。写出对称、反对称分量，
以及镜像模型在左右端点的误差。参考实现：

```python
import numpy as np
x = np.linspace(-1, 1, 101)
T = 293 + x*x + 2*x
even = (T + T[::-1]) / 2
odd = (T - T[::-1]) / 2
np.testing.assert_allclose(even, 293+x*x, atol=1e-12)
np.testing.assert_allclose(odd, 2*x, atol=1e-12)
np.testing.assert_allclose(even+odd, T, atol=1e-12)
```

答案：对称部分293+x²，反对称部分2x。只用even时，左端预测高2 K，右端低2 K。
中点反对称量为0。该练习已对应 `MemoryTests` 中的可执行测试，不需要MATLAB。

### C. 半指导：证明你的监督掩码没有泄漏

按训练TIME/SPACE索引构造50×101布尔矩阵，只污染其补集的未来标签，保持
独立初始输入不变。固定seed重新拟合；期望权重和预测逐位相同。随后故意让
输出scale从全标签计算，应该使污染试验失败。恢复实现后再通过。

验收：能解释加载数据和使用标签的区别；不能把首帧当成未知；不能改变随机
采样种子来掩盖问题；保留故意失败的结果，不能只提交最后通过截图。

### D. 半指导：定位级联接口错误

在新实验目录比较：①仅镜像；②预测方向记忆；③真实方向记忆的oracle诊断。
第三种只能用于分解误差，必须标成使用未来真值的诊断，不能放进自主部署结果。
分别报告阶段4初场和未来SMA/HTF误差，并说明初场偏差如何进入分支编码。

验收：①②不得读取真实stage4初场；使用同一冻结权重；不能只更新initial而
忘记branch；能区分上游径向误差、方向记忆误差和下游算子误差。这里③是练习
要求，不是本章已完成的实验，报告不能提前声称其结果。
