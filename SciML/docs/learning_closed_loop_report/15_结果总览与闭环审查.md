这是一条工作流程闭环，不是所有模块已经拼成一个端到端物理可微网络。
主动学习自己的模型只使用已揭示池标签，不借用全 37 例 UQ 模型权重；
设计阶段使用指定主动学习实验的最终 22 例模型。历史场解码是边界到场的单向串接，
没有把预测场反向反馈成完整机械/能量状态。制造问题也没有伪装成真实 SMA 标签。

“统一项目”指共享任务定义、数据权限和证据链，不指隐去不同实验的输入与训练协议。

## 15.4 原始规划与学习完成边界逐项对照

原参考报告的 WP4 推荐顺序是单阶段→共享换热→四阶段→多循环→跨材料/几何。
后续 WP5 是局部逆问题支线，WP6 是可信度与决策闭环。原计划还列出了物理损失和强制消融。
按照你“使用已有结果、不为学习多算一周”的调整，各项采用下列诚实映射：

| 原规划项 | 本次实施/教学证据 | 未实现或不能声称的部分 |
|---|---|---|
| 单阶段温度映射 | 以阶段2/4样本训练与分阶段评价坐标算子 | 不声称全部力学/相变场已经由同一时空网络输出 |
| 共享stage条件算子 | 两换热阶段共享权重，去stage消融，多种子 | 未证明共享结构在任何数据规模总更优 |
| 四阶段hybrid | 允许初态的四复合边界模型与换热场解码 | 非完整PDE神经closure、非全系统端到端能量投影 |
| 多循环rollout | 历史一致版本自主边界推进、明确重启、预测入口场解码 | 只有已有两/三循环支持；不编造当前63例后续循环或任意长时稳定性 |
| 跨材料/几何 | 输入定义的结构化OOD及失败原因、拒答 | 已检验不代表已通过性能门禁；未证明新材料可靠 |
| 物理约束和消融 | 真实硬初值/边界/范围约束；制造热方程完整损失链 | 制造PDE/能量消融不等于真实SMA能量损失全部可用 |
| 直接标量 vs 场后积分 | 标量头实际训练；观测端口积分；输出信息可辨识性审查 | 无完整端口/功/储能预测合同，不能造一个完整预测场积分COP对照 |
| 少观测逆问题 | 已知真值PINN和项目局部有效速率辨识 | 未进行实验物性联合标定或整个多物理求解器替代 |
| UQ与校准 | 多成员、有限样本校准、OOD、拒绝条件 | 噪声分解不可辨识；测试覆盖不等于任意OOD保证 |
| 两轮主动学习 | 固定池内揭示标签与重训、随机基线、多种子 | 没有新仿真闭环；科学增益仍是探索性证据 |
| Pareto安全逆设计 | 区间下界筛选、归档回查、数值/工程判断分开 | 无批准工程限值，不给“安全可制造”的结论 |
| frozen solver逐点回验 | 回查选中已有案例原始MAT、摘要和数值门禁 | 不是新设计运行新求解器，更不是实物实验 |
| 论文/申请材料 | 提供真实项目叙述及证据边界 | 不生成假论文级结论，不提交论文，不代替个人能力考核 |

## 15.7 两种审查不能互相代替

可读性审查逐章检查：

1. 问题是否先于术语出现，数学背景读者是否知道输入和目标。
2. 公式中的符号、单位、数组轴和训练/推理角色是否可追踪。
3. 是否有小例子从公式走到代码，错误实例是否解释原因。
4. 命令的目录与前提是否齐全，失败后是否知道该查哪个文件。
5. 练习是否给可检查答案与进阶验收，而不是“自行研究”。

技术完整性审查另外检查：

1. 章节中的配置、数值、图与实际源码和保存数组是否一致。
2. 源数据、切分、模型、scaler、权重和结果能否逐层绑定。
3. 自主推理是否没有真实未来信息，预算和对照是否公平。
4. 负结果、信息不足、历史版本、探索性测试是否完整披露。
5. 所有交付需求、命令、局部审查及回归是否在最终版本仍有效。

作者走查加自动证据检查可以发现很多问题，但不能假称有第二位独立人类读者已经读懂。
你个人是否能独立实现，要由第 14 章的实际提交检验；报告承诺提供学习与检验路径，不保证阅读即熟练。
