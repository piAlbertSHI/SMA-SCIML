# 第 14 章：分级练习、参考答案与独立扩展

## 14.1 从“看懂演示”到“自己实现”差在哪里

能解释一行公式、能照抄代码、能发现自己代码中的错误，是三个不同层次。
本章采用三层练习：A 层有明确输入输出和手算答案；B 层给接口与验收条件、由你完成实现；
C 层要求你先写实验协议，再独立设计扩展。不是把全部源码再运行一遍就算熟练。

建议第一次先看题目，自己写答案，再看提示，最后打开参考实现。
已看过答案后，应换一组输入或一个任务条件重新实现，不能用记住输出数值代替理解。
所有练习使用小数组或已有数据，不需要新增 MATLAB 工况。

每次提交建立一个自己的新目录，至少保存五件东西：

1. `problem.md`：输入、输出、单位、允许使用哪些标签、你要检验什么。
2. 你的源码：不能只提交截图。
3. 小测试：至少一个正确输入、一个必须被拒绝的错误输入。
4. 结果文件：包含种子、配置、来源摘要、原始指标，而非只保存最佳分数。
5. `reflection.md`：哪一个预测先被证据推翻，你如何诊断，还不能证明什么。

后面提到的“通过”都是对应练习的标准，不是论文门禁或工程安全认证。

## 14.2 A 层：八个可以手算或明确核对的参考练习

参考包实际调用部分生产模块，并用独立手算或解析解检查；它不训练项目模型。
源码：learning_exercises.py（原工作站归档，未随精简分发打包）。
运行前先尝试自行作答，输出目录必须不存在：

```powershell
python -u -m SciML.evaluation.learning_exercises --output-root SciML/results/learning-closed-loop-20260910/learning-exercises-user1
```

`reference_answers.json` 保存八题的实际输出；`summary.json` 保存源码摘要和检查范围。
`reader_mastery_verified=false` 是有意的：参考答案运行成功不能证明你已独立掌握。

### E01：广播让正确标签变成错误损失

题目：预测数组为 `[[1],[2],[3]]`，标签为 `[1,2,3]`。
先写出相减后的 shape 和全部元素；再实现只接受相同 `[N,D]` 形状的 RMSE。
这里 N 是样本数，D 是输出通道数，每个通道分别沿样本轴计算误差。

提示：NumPy 从最后一维对齐广播；`[3,1]` 与 `[3]` 得到 `[3,3]`。
错误差矩阵为 `[[0,-1,-2],[1,0,-1],[2,1,0]]`，不是三条样本各自的误差。

参考答案：先将任务定义中的标签整理为 `[3,1]`，正确逐通道 RMSE 为 `[0]`。
`strict_rmse` 直接拒绝 shape 不一致，而不是自动 reshape 任意输入。
任意 reshape 可能把错误列顺序藏起来；维度修复应在明确知道数据语义的地方发生。

验收：形状不一致、空数组、NaN 均被拒绝；再用两输出、非零误差的手算例子测试。

### E02：归一化能不能看到测试集

题目：`X=arange(12).reshape(6,2)`，前三行训练、后三行留出。
写一个只在训练行计算总体均值和标准差（ddof=0）的函数。
把留出行都加上 1,000,000，重新计算，哪些量应该不变？

提示：先选行再算统计量，不能先对全部 X 求均值再切分。

参考答案：训练均值 `[2,3]`，标准差两列都是 `sqrt(8/3)`，约 1.632993。
正确统计量逐位不变；错误的全局均值每列改变 500,000。
对于训练中恒定的列，参考函数保留均值，变换尺度用 1 防止除零。
这只是输入标准化约定，不是第 05 章残差修正应该采用 1 m 尺度的理由。

验收：输入数组未被原地修改；训练中 NaN 必须报错；未参与拟合的留出行不影响统计量。
注意：这里只证明 scaler 的权限；模型预测时仍必须检查实际输入有限，不能接受 NaN 推理。

### E03：亲手完成一次反向传播

题目：单参数模型 `y_hat=w*x`，x 为 `[1,2]`，目标为 `[2,4]`，初值 w=0。
损失是两个样本平方误差的平均值，学习率 0.1。求损失、梯度、更新后的 w 和新损失。

推导：`L(w)=((w-2)^2+(2w-4)^2)/2=2.5(w-2)^2`，所以 `dL/dw=5(w-2)`。
参考答案依次为 `10, -10, 1, 2.5`。实现用 PyTorch autograd，检查结果与手算完全相同。

这一步用最简单的梯度下降，不是 AdamW；先理解梯度指向和学习率，再读第 04 章的动量与权重衰减。
更新在 `torch.no_grad()` 中进行，避免把参数更新自身继续记入计算图。
如果改成循环，必须清理旧梯度，否则默认梯度累加会改变算法。

验收：不调用 backward，先独立算出答案；把初值改成 3，仍能预测梯度符号以及参数移动方向。

### E04：为什么 51 点不能恢复 101 点方向记忆

题目：令 x 在 [-1,1] 上均匀取 101 点，`T(x)=293+x^2+2x` K。
实现偶分量 `e=(T+reverse(T))/2` 和奇分量 `o=(T-reverse(T))/2`。
构造另一温度场 `T2=e-o`。能否只根据 e 区分 T 和 T2？

参考答案：e 为 `293+x^2`，o 为 `2x`；忽略奇分量的最大误差为 2 K。
两个全场的偶分量相同，奇分量相反，不能只凭偶分量判定哪个方向正确。
中心奇分量为 0，另外 100 点两两反号，因此只有 50 个独立奇分量自由度。

这是信息丢失的构造性例子，不是又训练一个插值器就能消除的误差。
本例是制造小数组；第 06 章另外使用真实 63 例验证项目接口关系。

验收：支持 batch；重组 `e+o` 恢复原值；反转两次恢复原值；中心为零；非法长度和 NaN 被拒绝。

### E05：不训练也能检查硬初始条件

题目：给一个未训练的 `CoordinateOperator`，输入 branch `[1,221]`、初场 `[1,2,101]`，
查询时间 `[0,0.5]`、位置 `[0,0.5,1]`。求输出 shape，并说明 t=0 应满足什么。

提示：输出布局为 `[工况,通道,时间,空间]`。
结构 `T=T0_interp+(1-exp(-4*tau))*scale*network` 在 tau=0 时修正项严格为零。

参考答案：shape `[1,2,2,3]`；t=0 的每个通道等于给定初场在三个位置上的值。
参考包检查误差精确为零。随机网络的未来预测并不因此正确：硬初值只证明一个结构性质。

验收：改随机种子仍满足初值；改未来查询时间不改变零时刻；用错误初场 shape 必须报错。
再解释为什么 `deeponet_no_ic` 对照不应使用相同的“初值必为零”断言。

### E06：用解析解审查 PDE 与能量残差

题目：第 07A2 章的制造热问题满足
`u_tau=Fo_s*u_xx`，u、x、tau 和 Fo 都已无量纲化。
八个连续区段中 `u=sin(pi*x)*exp(-pi^2*(累计Fo+Fo_s*tau))`。
先手算 `u_tau` 与 `u_xx`，再将解析函数传入实际残差函数。

参考推导：`u_tau=-pi^2*Fo_s*u`，`u_xx=-pi^2*u`，相减为零。
空间积分给出 `d/dtau integral(u dx)=Fo_s*(u_x(1)-u_x(0))`。
注意两端梯度的顺序，写反会把散热的符号反过来。

参考实现用自动微分计算点残差，用 32 点 Gauss 积分计算整体能量残差，
两者最大绝对值均应小于 1e-12。实际浮点数保存在答案文件，不把它们要求为逐位零。
这检查制造方程实现；真实 SMA 能量读出缺失的端口、储能和功信息不会因此自动补齐。

验收：能推导单位恢复 `dT/dt=(DeltaT/duration)*u_tau`；若改变长度 L，
能解释为何 `alpha=Fo*L^2/duration` 也相应改变。不要只调整 loss 权重掩盖量纲错误。

### E07：有限样本校准的秩

题目：13 个校准分数为 `[1,2,...,13]`，预测尺度为 1。
分别计算 90% 与 95% 的 `ceil((n+1)*coverage)`，指出有限区间是否存在。

参考答案：90% 的秩为 13，半宽为 13；95% 的秩为 14，必须记录有限区间不可得。
答案文件用 null 表示该无界情形，不将秩夹到 13。这里半宽不是标准差，也不是三 seed 的样本标准差。

验收：能解释为何本例的测试值也落入区间不等于 OOD 保证；
把校准集改成 19 条，先手算 95% 的秩为 19，再检查程序结果。

### E08：选点权限、并列排序和二维 Pareto

题目：候选 ID 顺序为 `b,a,c`，不确定性全相同，只选一个。
按生产模块的规则应选谁？揭示后能不能重复查询或查询 test ID？
另给最大化目标点 `(1,3),(2,2),(1,1)`，参考点 `(0,0)`，求 Pareto 集和超体积。

参考答案：并列按 ID 排序选 a；重复和不在 oracle 中的受保护 ID 均拒绝，拒绝后历史不变。
生产 API 是实验权限边界，不是能抵御 Python 反射的安全沙箱。
Pareto 点是前两个；矩形并集面积 `1*3+2*2-1*2=5`。
再加入 `(3,1)` 后面积为 6，增益为 1；不能简单把所有矩形面积相加。

验收：能区分“用候选预测选点”和“偷偷看候选真值选点”；
加入一个被支配点后超体积不增加；所有目标在参考点以下时为零。
小数组的增益为 1 不代替第 11 章真实归档候选的增益，也不证明工程安全。

## 14.3 B 层：少提示实现三个完整小任务

### B1：从原始表到一个可信标量模型

输入是已有 63 例与原始工况 split；先只预测 Qcool，单位 J。
独立实现：选择特征→检查重复工况→训练行 scaler→Ridge 与小 MLP→反归一化→逐工况误差→权重重载。
不得把原五输出模型直接删四列后声称这是原 benchmark；这是新的单输出教学实验。

建议接口：`fit(train_x, train_y, train_ids)` 返回模型；`predict(x)` 返回 `[N,1]`，
推理函数不接受标签。保存特征顺序、单位、scaler、网络结构、种子、预算和训练 ID。
已有测试集被看过，因此所有新比较称为探索，不以最好测试分数选择超参数后再宣称独立确认。

参考实现入口：第 04 章 `learning_scalar_benchmarks`，第 03 章数据练习。
先写自己的训练循环，再对照参考中的 zero_grad/backward/clip/step 顺序。
正确答案不是某个必达 RMSE：换输出数或结构后分数可以不同；必须保证任务、来源和重放自洽。

验收清单：三种子、相同输入的强基线、训练曲线；训练统计不受留出标签污染；
权重重载前后同输入预测一致；误差在 J 中报告；糟糕种子也保留。
故意换错一个特征列顺序，确保你的元数据检查能发现问题，而不是继续给出 shape 正确的错误预测。

### B2：最小 stage-conditioned DeepONet

从两个换热阶段中提取已有初场、控制和坐标；先固定本章使用的训练工况，不新增仿真。
独立写 branch 和 trunk：branch 输出 `[B,2,p]`，trunk 输出 `[T,X,2,p]`，
沿 p 维内积形成 `[B,2,T,X]`，再加硬初值结构。先选择 p=8 做接口验证。
这只是练习配置，不是原 24 维 latent benchmark 的无改动复现。

提示：先用全 1 latent 手算内积应该等于 p，再加入真实网络。
不能在未来时间查询时重新拼入真实末态或实际未来流量；观测入口预测与自主串接是两个不同任务。
先完成观测入口版本，再将第 05 章预测边界接入，分别报告误差。

参考入口：第 06 章 `MultiBranchDeepONet.forward`、`CoordinateOperator.forward/fit`。
评估要区分训练粗网格和原始细网格，不能把插值标签误称新增求解器真值。

验收清单：四个轴各自含义清楚；硬初值测试通过；未知坐标插值不会交换时间和空间；
POD/持久性基线具有相同输入权限；模型不一定胜出，但所有对照都有完整结果。

### B3：自己写两轮主动学习

把 37 条训练池作为唯一可查询的归档集合，固定 13 条校准和 13 条测试不进入池。
每个实验从 12 个已揭示工况开始，两轮各查询 5 个，最终为 22，不能把 stage 行当独立工况计预算。
独立实现 random 与 uncertainty 两策略，每种至少三种子、相同模型容量和训练预算。

每一轮的顺序应是：只取已揭示标签→重新拟合 scaler/模型→预测未揭示候选→选 5 个→
记录 ID 和选择依据→oracle 揭示→进入下一轮。测试标签只能在评价路径中使用。
不要借用第 09 章使用完整 37 例训练的集成权重，那会破坏从 12 例开始的实验。

参考入口：第 10 章 `ArchivedLabelOracle`、`one_experiment`，第 09 章 `LearningEnsemble`。
应记录各轮真实预算与 ID 集合，重新算每轮 RMSE，不仅画平滑后的平均曲线。

验收：12→17→22 且无重复查询；替换未揭示真值不会改变替换前的选点；
每一轮都有相同种子随机基线；如果 random 赢了，结论必须保留。
这三项 B 练习的源码与输出应由你提交后才能判断个人掌握，参考包不会自动伪造通过记录。

## 14.4 C 层：高阶任务应该怎样独立启动

下面不是新的后台任务队列，也不是本报告已经完成的科学结论，而是可独立实施的扩展规格。
前四项可以只用已有数据；第五项涉及新的物理信息或实验，应先取得数据与成本授权。

### C1：多步训练能否降低历史第三循环漂移

动机来自第 07C 章负结果：单步训练的神经模型第三循环误差大于 affine。
工作假设是训练—推理状态分布不同，而不是先假定网络太小。

实施步骤：

1. 保持同一历史 physics/pipeline、8/4 整工况划分，不混入主 63 例。
2. 在训练轨迹上构造两步或一个完整循环的可微展开，初态来源保持原契约。
3. 对比 teacher forcing 单步、纯预测递推多步、逐步增加预测输入比例三种方案。
4. 损失按状态通道尺度归一化；记录反传跨几步、是否截断梯度，不能 detach 后声称端到端多步训练。
5. 使用相同测试病例群体逐循环计算误差，保留 affine 和去记忆/跳重启对照的正确实验类别。

关键难点：当前代码有 NumPy/scikit-learn 边界及硬投影，不能简单在外层套 loss.backward。
若改为 PyTorch，需先证明未训练时与旧一步函数数值等价，再检查整条轨迹的梯度确实非零且有限。
投影是否可导、如何处理相变量边界，必须在设计说明中写清。

验收不是强制“第三循环必须赢”：要求公平预算、梯度连通测试、无未来标签输入、真实误差曲线，
并解释神经仍输时哪种假设被反证。现有历史轨迹少，不声称普适长时稳定性。

### C2：Fourier 算子跨分辨率测试

先区分空间查询插值、网络真正改变网格分辨率以及物理域改变，三者不是同一种泛化。
固定已有场与物理域，对训练监督网格、推理查询网格建立显式映射，保持所有方法可见标签相同。
检查 rFFT 频率索引、Nyquist 上限、逆变换长度和幅值归一化；有效 modes 不能超过当前可用频率数。

参考接口在第 06 章 `SpectralLayer` 与 `ConditionalFourier`。当前实现是时间条件的一维空间谱算子，
改为二维空间—时间 FNO 属于新模型，不是给旧模型改名。
验收：常数场、单正弦模式重建、不同奇偶长度、硬初值、原始 50×101 标签上的统一指标。
本数据 R/t 恒为 200，不能把跨分辨率结果写成跨独立厚径比泛化。

### C3：主动学习中的“多样性”是否值得加入

当前不确定性并列或集中时，候选可能非常相似。你可以增加训练尺度空间中的距离项，
或逐个贪心选择、每次对已选候选附近作惩罚；不要直接用未知候选标签计算距离。
先写 acquisition 公式、每项归一化、权重、并列处理、批次内更新顺序，再运行。

保留原 random/uncertainty/composite，增加一个新策略，匹配 12→17→22 和模型预算。
记录每轮覆盖的材料/几何/协议，判断改善是否只是偶然选到某个少数类别。
验收：重复 ID 拒绝、选样函数没有候选真值参数、污染未来标签不改变查询、三种子与负结果完整。
不确定性—误差相关变好不自动证明 Pareto 或工程安全也改善。

### C4：从现有材料 OOD 失败设计迁移实验

首先回答“可学习的物性输入是什么”，而不是只增加另一个类别编码。
若现有请求包含可用物性，先核对单位、来源与材料覆盖，避免从结果文件反推输入物性。
若仅有两类材料与 7 个少数类样本，可演示少样本适配，但不能证明对第三种未知材料可靠。

对照至少包括类别-only 原模型、物性输入模型、物性+少量适配标签模型；
适配预算、哪几个目标材料标签被揭示、剩余测试病例必须在运行前固定并单独记录。
只允许使用已有结果，任何新观测需求先作为待授权条件列出。
验收：训练中物性列确有变化且数据梯度不为零；与简单拒绝规则比较；不把常数列权重衰减叫物性学习。

### C5：真正的场到能量读出与实验标定

第 07A1 章已经说明只有温度场不能唯一确定本项目的热量、储能和功。
要推进这项高阶工作，先扩展合同：独立端口温度/质量流量、物性与积分权重、
机械加载/卸载功符号、储能分量的独立来源、环境交换、补偿前后的值及方法标签。

接口草案可以写为 `readout(fields, ports, properties, work, storage, boundary_contract)`，
输出每项有单位的积分与未闭合残差。信息缺失时应拒绝给出“独立闭合”，不能以残差定义某一储能项再回算零残差。
先在已知答案的制造问题和第 07A1 章已有端口积分上测试，确认符号、时间网格和积分误差。

只有取得新的完整记录或真实实验数据后，才进一步做设备能量验证或物性标定。
本报告未授权、未运行新的仿真或实验；此处交付的是实现规格与前提，不是已通过的物理验证。

## 14.5 掌握程度量表：如何知道自己可以独立做下一步

每项按 0–3 分自评：0 无法解释；1 能跟着答案复现；2 能独立实现并测试；
3 能构造失败例、定位原因并解释证据边界。需要提交的代码和记录比自评分更重要。

| 能力 | 必须拿出的证据 | 对应练习 |
|---|---|---|
| 数据权限与单位 | 训练统计污染测试、case 隔离、列顺序合同 | E01/E02/B1 |
| 神经训练 | 手算梯度、完整循环、曲线与重载 | E03/B1 |
| 算子结构 | branch/trunk 形状、硬初值和不同网格测试 | E04/E05/B2 |
| 物理残差 | 链式法则、单位、解析/数值对照 | E06/C5 |
| 可信预测 | 校准秩、无界情形、OOD 不能保证的解释 | E07/C4 |
| 决策闭环 | oracle 日志、预算、并列排序、超体积手算 | E08/B3/C3 |
| 长时与科学判断 | 同群体循环误差、负结果、可微递推检查 | C1/C2 |

建议最低进阶条件：七项均至少 2 分；数据权限、物理残差和决策闭环中至少两项达到 3 分。
这是学习建议，不是统计认证；不必为了分数隐瞒不会的地方。
若能运行但无法解释某个 shape 或单位，回到对应 A 题；若能解释但不能定位坏结果，回到第 13 章。

最终口头自测：不用读源码，向另一个人说明“一条原始物理工况如何变成训练张量，
网络如何更新，怎样防泄漏，如何给出区间，怎样选下一点，为什么回查不是新实验”。
然后从空文件完成一个 B 任务，并对一个 C 任务写出明确可检验的协议。
只有这个过程的实际提交被检查后，才有个人掌握证据；当前演示和报告不冒充这一证据。
